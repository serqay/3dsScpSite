scpcb3ds_new.3dsxHomebrew Launcher scpcb3ds_new.ciaInstallable with FBI

All versions: GitHub Releases. The Old 3DS build always uses the low profile (shorter view distance, cheaper animation). The New 3DS build has sharper textures and stereoscopic 3D.

Step 2: install

  1. Your console needs custom firmware and the Homebrew Launcher.
  2. .3dsx: copy the file to sdmc:/3ds/ on the SD card and start it from the Homebrew Launcher.
    .cia: copy it anywhere on the SD card and install it with FBI.
  3. Sound: dump your console's DSP firmware (the "DSP1" homebrew) so that sdmc:/3ds/dspfirm.cdc exists. Without it the game runs silently.
  4. Keep at least 300 MB free on the SD card.

FAQ

Does it work in an emulator?

Yes, it runs in Azahar (the Citra successor). Use the .3dsx build that matches the console model you choose.

Is it finished?

It is a demo: you can play through the facility and reach the endings, but expect bugs.
